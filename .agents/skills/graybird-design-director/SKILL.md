Preserve the original observation experience alongside nest/archive routes.

Update DESIGN.md only when the user's direction genuinely changes. Check whether a proposal belongs to this bird's world rather than demonstrating a tool. Prefer data-driven content and reusable static components. No new font/framework/library solely to comply with the imported pack.
