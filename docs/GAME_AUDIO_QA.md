# 花生猎人提示音交付与验收

基于 main `4ea2c94c589a7731c03c8a4dd79d7c21cb53e009`，2026-10-09。实现完成，等待浏览器及真机验收；未部署。

## 改动

- `play/combat-feedback.mjs`：20 种短合成音效，包括开始/继续、发射/命中/击败、花生/奖励、进化、护盾受击/死亡/复活、Boss 预警/登场/击败、反击充满/释放、购买/余额不足；保留擦弹和战后补给提示。
- 发射与命中分别节流至 90/70ms；最多 8 个声部，高优先级提示可替换低优先级声部。淡入淡出，最大单声部峰值 0.085，满音量时合成峰值上限 0.68。无背景音乐、下载资源或新增运行依赖。
- 主增益复用已有声音开关与音量偏好，沿用 localStorage 保存。关闭或音量归零立即截断声部；暂停、后台和重开清理声部与待解锁动作，不补播旧模拟事件。首次开始、开启声音或当前有效操作调用 AudioContext.resume，失败不阻塞游戏。
- `play/game-core.mjs`：补上死亡和 Boss 预警事件，区分普通花生与奖励。经济、伤害和难度参数不变。
- `play/play.js`：接入开始/继续/复活/购买，用户操作提示可等待当次解锁；购买余额不足时允许点击，给出缺少花生数量和失败音，不扣费。已满级和战斗中的购买限制保留。
- `play/index.html` 与模块导入更新脚本缓存版本，图像和 CSS 版本保留。

## 后续验收步骤

1. 桌面与安卓浏览器首次进入时应静音；点击开始后出现开始音和低音量射击音。没有 AudioContext 时仍可玩。
2. 开启声音开关、调整音量、关闭声音，确认即时生效；刷新确认设置保留，刷新本身不自动播放。
3. 连续射击与密集命中下确认无爆音，拾取普通花生/奖励、进化、护盾碎裂、死亡、买命复活可区分。
4. Boss 接近、登场与击败分别提示；充满和释放反击可区分。
5. 暂停/后台立即停止，继续只播当前事件；连做多次重开和复活，无旧音补播或声部泄漏。
6. 军械库购买成功与余额不足分别提示；余额不足不扣费，原存档与玩法保持。

原 Muse 报告提到的复活安全性、HUD 花生计数及 36 杀芯片冷却问题未纳入本轮声音任务。
