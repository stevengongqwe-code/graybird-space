01 / 07营救计划 / THE PLAN

动物园的伙伴们，正在悄悄靠近小黑屋。

夜色降临，一场救援正在酝酿。

02 / 07最终决定 / THE DECISION

最后一分钟，行动已经无法撤回。

所有目光聚焦在最后的按钮上。

03 / 07启动 / THE SIGNAL

那一按，所有人都听见了。

这一次，要把灰鸟带回来。

04 / 07零点 / MIDNIGHT

当时钟跨过零点，光终于出现。

信号穿过黑夜，通往未知的方向。

05 / 07重生 / RETURN

为了一个朋友，他们试着创造奇迹。

一道金色光芒照亮了整个大厅。

06 / 07突围 / BREAKTHROUGH

那一夜，所有人的希望都指向同一个名字。

火光中，灰鸟的身影再次出现。

07 / 07守护 / AFTERGLOW

真正让一只鸟回来的是，有人始终不愿放弃。

故事没有停在奇迹发生的那一刻。
